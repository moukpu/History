# Asset sources: caravan-runner

- `steppe-background.webp`: derived WebP from `wikimedia/caravan_runner/steppe_background.jpg`, Wikimedia Commons, CC-BY-SA. Source file came from the provided `minigame_assets` bundle.
- `caravan-hero.webp`: AI-generated historical illustration, stored as a static project asset.
- `camel_body.png`, `camel_leg_front_left.png`, `camel_leg_front_right.png`, `camel_leg_back_left.png`, `camel_leg_back_right.png`: color Kazakh rider on Bactrian camel split into skeletal animation layers from the project sprite atlas.
- `raider_body.png`, `raider_leg_front_left.png`, `raider_leg_front_right.png`, `raider_leg_back_left.png`, `raider_leg_back_right.png`: left-facing color raider-on-horse sprite split into skeletal animation layers from the project sprite atlas.
- `fallen-tree.webp`, `rock.webp`, `cloth.webp`, `spice-jar.webp`, `scroll.webp`, `coin-pouch.webp`: transparent game sprites derived from the project sprite atlas.

Old SVG primitives, Muybridge silhouette sheets, and temporary fake frame animation are not used by the game.
